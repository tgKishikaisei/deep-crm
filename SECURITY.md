# Безопасность Deep CRM

## Как сообщить об уязвимости

Не открывайте публичный issue. Нажмите «Report a vulnerability» на вкладке **Security** этого репозитория или напишите мне в Telegram: [@BehruzAvezmatov](https://t.me/BehruzAvezmatov). Опишите шаги воспроизведения и что удалось получить. Я отвечаю в течение нескольких дней и сообщаю, когда выйдет исправление.

Исправления выходят только для ветки `main`.

## Что защищено

**Доступ к данным.** Правила доступа собраны в `crm/access.py`. Менеджер видит своих клиентов, свои сделки и задачи этих сделок, администратор видит всё. Те же правила применяют списки, карточки, формы, поиск Ctrl+K, календарь и REST API. Чужой объект отвечает 404, а поля «клиент» и «сделка» в формах и сериализаторах принимают только свои id.

**Вход.** django-axes блокирует пару «логин + IP» на час после пяти неудачных попыток. IP берётся с учётом числа доверенных прокси (`TRUSTED_PROXY_COUNT`). Админка живёт по адресу из `ADMIN_URL`, на `/admin/` стоит ловушка admin-honeypot. API принимает только сессию, Basic-auth выключен. Swagger и Redoc открыты только сотрудникам.

**Браузер.** CSP со списком разрешённых CDN, `frame-ancestors 'none'`, `object-src 'none'`, Permissions-Policy. Все 17 скриптов и стилей с CDN закреплены на точных версиях с SRI-хэшами. Данные из API попадают в HTML через экранирование, данные для графиков через `json_script`.

**Продакшен.** Настройки разделены на `dev`, `prod` и `test`. `prod` не стартует со слабым `SECRET_KEY` или пустым `ALLOWED_HOSTS`, включает HSTS, secure-cookie и `SECURE_PROXY_SSL_HEADER`. Образ Docker собирается в несколько стадий, ставит зависимости по хэшам, работает от пользователя с uid 10001 на read-only файловой системе без Linux capabilities. Postgres и Redis не публикуют порты наружу, Redis требует пароль.

## Автоматические проверки

GitHub Actions на каждый push:

- 35 тестов, включая тесты доступа к чужим данным, XSS в поиске и графиках, заголовков безопасности и блокировки после перебора;
- `manage.py check --deploy --fail-level WARNING` с prod-настройками;
- `makemigrations --check`;
- `pip-audit` по зафиксированным зависимостям;
- `bandit` по коду приложения;
- `gitleaks` по всей истории коммитов;
- сборка Docker-образа.
